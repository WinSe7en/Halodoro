# Halodoro

A focus timer for the Mac menu bar. Focus blocks, breaks and plans are shown as a glowing Halo around your notch, or across the top edge of your screen on a Mac without one.

## Support

Found a bug or have a question? [Open an issue](https://github.com/WinSe7en/Halodoro/issues).
Please say which Mac and macOS version you use and what you were doing when it happened.

## Privacy

Halodoro collects nothing and makes no network connections. See the [privacy policy](privacy.md).
